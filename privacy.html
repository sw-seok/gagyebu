개인정보처리방침

가계부 수집 · 시행일 2026-11-20

「가계부 수집」(이하 “이 앱”)은 한 가족이 개인 가계부를 위해 직접 만들어 쓰는 도구입니다. 사용자는 앱을 만든 본인뿐이며, 일반에 제공하지 않습니다.

1. 접근하는 정보

  • Google 권한: https://www.googleapis.com/auth/gmail.readonly (Gmail 읽기 전용) 하나만 요청합니다.
  • 읽는 메일: 뱅크샐러드 데이터 내보내기 발신 주소에서 온, zip 첨부가 있는 최근 메일만 검색합니다.
  • 가져오는 것: 해당 메일의 발신자 헤더(대상 메일이 맞는지 확인용)와 zip 첨부파일만 가져옵니다. 메일 본문은 저장하거나 기록하지 않습니다.

2. 이용 목적

사용자 본인의 금융 거래내역(뱅크샐러드 내보내기 파일)을 가계부로 자동 정리하기 위해서만 사용합니다.

3. 저장과 보관

  • 내려받은 파일과 인증 토큰은 사용자 본인의 PC에만 저장됩니다. 이 앱은 별도 서버를 운영하지 않습니다.
  • 처리한 메일은 중복 다운로드를 막기 위해 메일 ID만 기록합니다.
  • 사용자가 파일을 지우면 즉시 삭제됩니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 전송·판매·공유하지 않으며, 광고나 다른 용도로 쓰지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 하지 않는 일

  • 메일 보내기, 삭제, 수정, 라벨 변경을 하지 않습니다.
  • 대상이 아닌 메일의 본문을 읽지 않습니다.

6. 권한 철회

사용자는 언제든지 Google 계정 → 보안 → 타사 앱 액세스에서 이 앱의 권한을 삭제할 수 있습니다. 삭제하면 이 앱은 더 이상 Gmail에 접근할 수 없습니다.
